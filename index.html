Offline storage

Workout records are saved on this device. Data does not automatically sync to other devices. Export a backup regularly so you don't lose your history if Safari storage is cleared or you change phones.

Saved data & recovery

See whether this device can read your saved records. A second local recovery copy is maintained on supported browsers, but a downloaded backup is still important.

Checking device storage…

Safari Private Browsing, clearing website data, using a different browser, or device storage eviction can remove local records. A JSON backup is the safest way to preserve them without cloud sync.

Open the GitHub Pages URL in Safari, tap Share, and choose Add to Home Screen. Open Gym Log once online to cache it for offline use.
